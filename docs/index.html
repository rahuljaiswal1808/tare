How it works

TARE scores the static design of MCP servers on 6 dimensions:

D1 Tool Surface (15%) — total tool count
D2 Schema Footprint (25%) — token cost of schemas
D3 Progressive Disclosure (20%) — runtime discovery
D4 Response Discipline (20%) — pagination/shaping params
D5 Description Quality (10%) — usage guidance in descriptions
D6 Redundancy (10%) — duplicated schema fragments

Each dimension is green / yellow / red (100 / 60 / 20 pts). Weighted sum = Design Score.
